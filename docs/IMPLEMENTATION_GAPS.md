## D. Known limitations of the Phase 1 implementation

* Tale nesting (frame-within-frame stories) is not inferred; `parent_story_id`/`nesting_level` stay `null` unless supplied.
* Title detection is regex-based and line-anchored; titles embedded in running text are missed (reported via warnings).
* `simple_tokenize` does not split clitics; ArabicNameNet text matching therefore misses prefixed forms (e.g. "وشهريار").
* No morphological analyser is integrated (legacy used Stanford/Farasa; a modern choice, e.g. CAMeL Tools, is a Phase 2 decision).
* `LexicalTriggerEvidence` is not a scientific activation function.
* `ansg.anhc-record/0.1` is a schema defined here; if the original ANHC files have a different format, an importer is required.
* Legacy scripts are untouched and still non-functional as documented in `docs/REPOSITORY_AUDIT.md`.
