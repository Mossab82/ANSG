## ما بقي `pending` قبل أي إدخال نص

1. قرار المالك في ترخيص NC-SA لاستعمال ANSG، وفي توافقه مع تراخيص المصادر الحالية.
2. حقوق الطبعة الحديثة والمصدر الرقمي لكل نسخة تُختار.
3. اختيار نسخة واحدة لكل عمل وتسجيلها مع بصمتها. الافتراضي المقترح هو نسخة pri، دون حسم.
4. تحديد مؤلفات الجاحظ المقصودة، ومعالجة الأعمال ذات النسبة المشكوك فيها.
5. علاج عيوب نسخة الأغاني (المجلد 10)، أو البحث عن نسخة أخرى.
6. إزالة التكرار مع سجلات البناء المباشر الـ810 والأعمال الستة قبل أي قسمة.
7. حدود القصص: هذه أعمال أدب ونثر ورسائل وتراجم، وليست قصصاً مقسمة. لا تُقبل كوحدات سردية قبل مراجعة الحدود.
