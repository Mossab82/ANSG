# Curated heritage LoRA pilot (research-only)

## Frozen source corpus

The Kaggle pilot reads the actual text file `data/corpora/classical_arabic/stories.jsonl` from the immutable Git commit `da54c488c9e94d049b5ed38b28a3d8005aac88f7`, generated by [GitHub CPU extractor #43561547592](https://github.com/Mossab82/ANSG/actions/runs/43561547592). This source contains 20 pages and 195,197 words: four volumes of Arabian Nights, the separately published Sinbad page, and 15 Kalila wa Dimna chapters.

The standalone Sinbad page is *excluded* from this pilot because of likely overlap with the anthology. The pilot trains on the four anthology parts and selected Kalila chapters, validates on three distinct Kalila chapter pages, and reserves two additional Kalila chapter pages untouched for later tests. These are **page/cycle groups**, not human-annotated independent stories; nested stories may share a frame or recurrent formulas. The Kalila validation distribution also differs from the Nights source distribution.

Run `python scripts/validate_classical_corpus.py` to verify each source text against the recorded SHA-256 and the exact grouping. The workflow runs this gate before any GPU launch.

## Scope and scientific boundaries

This is Qwen2.5-1.5B-Instruct LoRA pretraining adaptation on public classical narratives, **not** the ANSG architecture with CSAM/DAL/CKG and **not** a replication of dissertation metrics. The source corpus must still undergo exact-edition/license review for any published dataset or commercial redistribution. No generated story-quality or cultural authenticity claim follows from cross-entropy loss.

Pilot GPU runs are normally manual (`workflow_dispatch`); a single approved trigger `TRIGGER_CURATED_CORPUS_20261114.txt` initiates the initial test on merge. No further push to other files auto-starts a GPU run.
