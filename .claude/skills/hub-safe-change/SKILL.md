# تعديل آمن (ANSG / AqabaIMS)

ينفذ فقط عند طلب صريح من المستخدم.

1. **فرع منفصل**: لا عمل على الفرع الافتراضي. استخدم فرع الجلسة المحدد أو `hub/<وصف-قصير>`.
2. **افهم قبل التعديل**: اقرأ الملفات المعنية و`docs/PROJECT_GOVERNANCE.md` (في ANSG).
3. **اختبار أولًا** حين يكون السلوك قابلًا للاختبار؛ ثم التعديل الأدنى.
4. **شغّل الاختبارات**: في ANSG `python -m pytest -q` (أو المجموعة ذات الصلة). سجّل الناتج الفعلي، لا ملخصًا متخيلًا.
5. **تقرير diff**: `git diff --stat` + شرح كل ملف تغيّر ولماذا.
6. **توقف واطلب الموافقة** قبل: الدمج، النشر، فتح PR، تعديل قاعدة بيانات الإنتاج، أو أي اتصال بخادم حقيقي.
7. **أسرار وبيانات**: لا أسرار في الملفات؛ لا بيانات طلبة/موظفين في الاختبارات (استخدم بيانات مصطنعة).

اكتب التقرير النهائي بصيغة مهارة `hub-report`.
