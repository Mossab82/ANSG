# صيغة تقرير Personal AI Hub

اكتب بالعربية الطبيعية (الإنجليزية فقط للمراسلات والوثائق الدولية). الترتيب إلزامي:

1. **ملخص قصير** — 2 إلى 4 أسطر.
2. **نتائج موثقة** — كل بند معه: الرابط الرسمي أو DOI (معرّف فريد)، تاريخ التحقق (YYYY-MM-DD)، المنصة = `Claude`، الحالة، الخطوة التالية.
3. **إجراءات عملية** — قائمة مرقمة بما يحتاجه المستخدم.
4. **ما تعذر التحقق منه** — بصراحة، مع السبب (لا صلاحية، الصفحة لا تفتح، المعلومة غير منشورة).

## صفوف السجلات

أعد الصفوف كجدول Markdown بأعمدة السجل الهدف بالترتيب نفسه (انظر `.claude/hub/HUB_CONFIG.md`)
حتى ينسخها المستخدم أو ChatGPT. لا تكتب في السجل مباشرة.

قبل إضافة صف: قارن الرابط الرسمي/DOI بما في السجل الحالي؛ إن وُجد فاكتب "تحديث حالة" بدل صف جديد.

## حالة التنفيذ

استخدم فقط: `منفذ ومتحقق` / `منفذ دون تحقق` / `غير منفذ — يحتاج المستخدم` / `متعذر`.
لا تكتب "تم" لشيء لم تتحقق منه بأداة في الجلسة نفسها.
